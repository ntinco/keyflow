# macOS hotkeys: captura de pantalla

Referencia operativa corta para no volver a consultar lo mismo.

## Capturas

| Acción | Hotkey |
|---|---|
| Pantalla completa | `Shift + Command + 3` |
| Área seleccionada | `Shift + Command + 4` |
| Ventana o menú | `Shift + Command + 4`, luego `Space` y clic |
| Abrir controles de captura/grabación | `Shift + Command + 5` |
| Touch Bar, si existe | `Shift + Command + 6` |
| Cancelar una selección | `Esc` |

### Copiar al portapapeles en vez de guardar archivo

Añade `Control` a la combinación. Ejemplos:

- Pantalla completa al portapapeles: `Control + Shift + Command + 3`.
- Área al portapapeles: `Control + Shift + Command + 4`.

## Ajustes útiles al seleccionar un área

Con `Shift + Command + 4`:

- Mantén `Space` mientras arrastras para mover el rectángulo sin cambiar su tamaño.
- Tras `Shift + Command + 4`, pulsa `Space` para cambiar a captura de ventana.
- En captura de ventana, mantén `Option` al hacer clic para excluir la sombra.

## Grabación y destino

`Shift + Command + 5` abre la interfaz de Captura de pantalla. Desde **Opciones** puedes elegir:

- grabar toda la pantalla o una porción;
- temporizador;
- destino de guardado;
- mostrar u ocultar la miniatura flotante.

Por defecto, las capturas se guardan como PNG y las grabaciones como MOV. Los atajos se pueden cambiar en **Ajustes del Sistema > Teclado > Atajos de teclado > Capturas de pantalla**.

## Regla de memoria

- `3` = toda la pantalla.
- `4` = elegir qué capturar.
- `5` = panel completo de captura/grabación.
- `Control` = copiar al portapapeles.
